# Компоненты сторонних разработчиков

Собственный код Орбиты: MIT, см. `../LICENSE`. Qt, PySide6 и Shiboken
поставляются как отдельные динамические библиотеки под применимыми условиями
LGPLv3; полные тексты LGPLv3/GPLv3 и уведомления включены в подкаталоги ниже.
MIT Орбиты не меняет лицензии этих библиотек или их сторонних компонентов.

`sources.json` содержит исходные URL, версии и SHA-256 полных архивов Qt/PySide.
Соответствующие неизменённые архивы должны быть доступны рядом с бинарным
релизом в отдельном архиве библиотечных исходников. Одного этого README
для их предоставления недостаточно.

Пользователь вправе изменять LGPL-библиотеки и исследовать работу приложения
для отладки таких изменений. В onedir-сборке они находятся в `_internal`.
Закройте приложение, сделайте копию папки и замените согласованный комплект
DLL/PySide6/Shiboken совместимыми сборками для той же архитектуры/ABI и Python.
Можно также запускать MIT-исходники Орбиты с собственным комплектом библиотек.
Блокировки замены или проверки подписи заменяемых библиотек в приложении нет.

Архивы Qt содержат собственные инструкции сборки; для PySide6 используйте
`pyside-setup/README.md` в исходном архиве и
https://doc.qt.io/qtforpython-6/building_from_source/index.html .
Заявление о наличии источников относится к реально приложенным архивам,
не к обещанию будущей загрузки.

Исходники Qt не менялись. Локальная упаковка исключает неиспользуемые
Virtual Keyboard и PDF-плагин; это изменение состава пакета, не кода Qt.
Дополнительные уведомления Python/OpenSSL/ICU/tzdata/PyInstaller находятся
в соответствующих подкаталогах.
