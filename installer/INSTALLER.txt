Орбита — локальные автоматизации для Windows

Установка выполняется только для текущего пользователя, без обязательного
запроса прав администратора. Перед установкой или обновлением завершите
Орбиту через системный трей → Выход. Крестик только скрывает панель.

Папка программы по умолчанию: %LOCALAPPDATA%\Programs\Orbita.
Личные данные хранятся отдельно. Установка и обновление их не удаляют.
Если раньше использовалась переносимая версия, её стандартный профиль
будет найден приложением автоматически. Файлы переносимой версии остаются на месте.

Автозапуск при входе в Windows не включается установщиком. Настроить его
можно в самом приложении. При переходе с переносимой версии отключите
прежний автозапуск и включите его снова из установленной версии.

При обычном удалении предлагается сохранить или удалить личные данные;
по умолчанию они сохраняются. Тихое удаление всегда сохраняет данные.
Отдельные пользовательские профили AUTOMATION_HOME не удаляются.

Приложение и установщик пока не подписаны: Windows может показывать
предупреждение о неизвестном издателе. Установщик не отменяет это предупреждение.

Проверенная платформа: Windows 11 x64. Для других ОС готовых пакетов нет.
Исходники и лицензии: https://github.com/Technomedved/orbita
