# Орбита / Orbita

Локальная панель автоматизаций для Windows: погода выбранного места, напоминания,
планы на сегодня и завтра, личные проекты и необязательная практика IBM Db2.
Стеклянный интерфейс, работа в трее и собственная история в SQLite.
Для обычной работы не нужны ChatGPT, платный API, почта или сетевой сервер.

Текущая версия: **0.9.2**, предварительная desktop-версия.
Проверенная среда — Windows 11 x64. Другие Windows требуют отдельной проверки.
macOS, Linux, Android, iOS и TV ещё не выпущены.

## Возможности

- Расписания: однократно, ежедневно и по дням недели, с часовыми поясами.
- Ручной запуск, пауза, история, восстановление и защита от повторов.
- Напоминания: «Выполнено» и «Отложить на 15 минут».
- Погода на сегодня и завтра через Open-Meteo; место выбирает пользователь.
- Проекты: заметки, ссылки, чек-листы и напоминания.
- Задания Db2: сохранение ответа и самопроверка, без встроенного сервера Db2.
- Тихий режим и очередь уведомлений; JSON-публикация через `--publish-file`.

Новый профиль пустой: автоматизации выключены до настройки.
Учебные ответы не получают фиктивной автоматической оценки.

## Скачать и запустить

[Установщик 0.9.2 для Windows 11 x64](https://github.com/Technomedved/orbita/releases/download/v0.9.2/Orbita-Setup-0.9.2-Windows-x64.exe).
Устанавливает программу для текущего пользователя без обязательного повышения прав.
Ярлык в меню «Пуск», обновление поверх установленной версии, удаление через
«Установленные приложения». Автозапуск настраивается отдельно в приложении.

[Переносимая версия 0.9.2](https://github.com/Technomedved/orbita/releases/download/v0.9.2/Orbita-0.9.2-Windows-x64.zip).
Распакуйте целиком и запустите `Orbita.exe`, сохраняя рядом `_internal` и остальные файлы.
Отдельный Python готовым пакетам не требуется.

[Страница предварительного выпуска](https://github.com/Technomedved/orbita/releases/tag/v0.9.2):
контрольные суммы, ограничения и исходники библиотек. GitHub **Source code** —
исходники приложения, а не готовая программа.

Перед установкой/обновлением завершите Орбиту через меню трея → Выход.
Личные данные сохраняются отдельно от программы. При обычном удалении
предлагается оставить или удалить показанный стандартный профиль; по умолчанию
данные сохраняются. Тихое удаление всегда сохраняет профиль.
Переход с переносимой версии и особенности: [установка](release_docs/INSTALLATION.md).

Приложение и установщик не подписаны: возможны предупреждения Windows.
Автоматическое обновление пока не реализовано. Реально проверена Windows 11 x64.

## Запуск из исходников

Нужен Python 3.12. Из корня проекта в Windows PowerShell:

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-desktop.txt
.venv/Scripts/python.exe orbita_entry.py
```

Контрольная среда: Python 3.12.14, PySide6 6.12.0, PyInstaller 6.22.3.
Зависимости закреплены в `requirements-desktop.txt`.

```powershell
.venv/Scripts/python.exe run_checks.py --core
.venv/Scripts/python.exe run_checks.py
.venv/Scripts/python.exe build_desktop.py
```

Windows-результат: `dist/Orbita/Orbita.exe` вместе со всей папкой сборки.
Результаты проверок создаются локально в `data`, в Git не включаются.
Учебные SQL-примеры в настоящей Db2 в контрольной среде не исполнялись.

## Данные и разработка

Новые Windows-профили хранятся в `%LOCALAPPDATA%/Orbita`.
Существующая база прежнего профиля автоматически сохраняет свой путь.
`AUTOMATION_HOME` позволяет выбрать отдельный профиль для разработки.
Личные базы, журналы, пароли и резервные копии не входят в репозиторий.
