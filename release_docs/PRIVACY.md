# Данные и приватность

Орбита работает с локальным профилем текущего пользователя. Аккаунт разработчика, ChatGPT, корпоративная почта, платный API и сетевой сервер не требуются. В поставку не входят чья-либо база, журналы, ответы, почтовые пароли и история разработки.

В SQLite сохраняются созданные задачи, расписания, результаты, уведомления, проекты, учебные ответы и настройки. Резервные копии миграций хранятся рядом с базой. Журнал ошибок также локальный. Профиль приложения не зашифрован самой Орбитой: доступ к нему определяется правами пользователя ОС. Автоматической синхронизации между устройствами нет.

Сеть используется для необязательной погоды:

- Поиск города передаёт его название Open-Meteo по запросу пользователя.
- Системное определение запрашивает службу местоположения ОС только после отдельного действия или ранее сохранённого согласия на повторение при открытии. Координаты округляются до двух десятичных знаков перед запросом пояса.
- Прогноз передаёт выбранные координаты Open-Meteo. Определение по IP и постоянное отслеживание не используются. HTTP-провайдер видит обычное соединение клиента.

Ссылки проектов и справочные ссылки открываются по нажатию в браузере. Учебные SQL-ответы никуда автоматически не отправляются; действие для Codex только подготавливает текст. Встроенной автоматической ИИ-проверки нет.

Погоду можно не настраивать. Проекты, напоминания, история и учебный контент доступны без интернета.
