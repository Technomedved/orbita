# Установка, обновление и удаление

Для Windows 11 x64 доступны установщик и переносимый ZIP. Python, ChatGPT и
платный API не нужны. Установщик и приложение пока не подписаны; Windows
может показывать предупреждение о неизвестном издателе.

## Установщик

Запустите `Orbita-Setup-0.9.2-Windows-x64.exe` обычным пользователем.
Установка не запрашивает повышение прав и пишет только в профиль этого
пользователя. По умолчанию: `%LOCALAPPDATA%\Programs\Orbita`.
Добавляется меню «Пуск» и запись в «Установленные приложения».
Ярлык рабочего стола необязателен и изначально выключен.
Автозапуск Windows включается только в настройках самой программы.

Не запускайте установщик через «От имени администратора»: это не требуется.
Корпоративные ограничения установки определяются администратором организации.

## Обновление

В меню значка Орбиты в системном трее выберите «Выход». Крестик окна только
скрывает панель. Запустите новый установщик: он использует прежнюю папку,
заменяет свои зависимости и сохраняет личную базу отдельно от программы.
При работающем приложении установка остановится до полного выхода.
Принудительного завершения процессов и автоматического обновления нет.

При переходе с переносимой версии завершите её через трей. Стандартная
прежняя база находится автоматически. Сам ZIP/прежняя папка не удаляются.
Если использовался AUTOMATION_HOME, оставьте этот явный профиль для запуска
или перенесите данные по [инструкции](PORTABLE.md).
Ранее включённый автозапуск переносимой версии переключите из настроек:
выключить старый, запустить установленную Орбиту, включить снова.

## Удаление

Полностью завершите Орбиту. Откройте «Установленные приложения» Windows
или пункт удаления в меню «Пуск». В обычном режиме предлагается удалить
также показанный стандартный профиль. **«Нет» выбрано по умолчанию**:
база и резервные копии остаются для повторной установки.
«Да» удаляет напоминания, проекты, ответы, историю, настройки и резервные
копии только в показанной папке. Другие профили AUTOMATION_HOME не затрагиваются.
Тихое удаление всегда сохраняет личные данные.

Удаляется только собственная запись автозапуска установленной версии.
Отдельный автозапуск другой переносимой копии не изменяется.
Не помещайте личные файлы в `_internal`, docs, licenses или training:
это каталоги программы, заменяемые при обновлении.

Реально проверена Windows 11 x64. ARM64-эмуляция и другие Windows требуют
отдельной проверки; готовых пакетов других ОС нет.
