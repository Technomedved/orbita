# Перенос и требования

## Папка программы

Windows-поставка содержит `Orbita.exe`, `_internal`, руководство и учебные материалы. Python и Qt включены в зависимости; отдельная установка Python или Codex не нужна. Программа не использует каталог или имя Windows-пользователя разработчика. Можно перенести всю папку в другой путь, в том числе с пробелами и кириллицей.

Сам файл exe без `_internal` не является полной программой. Установщик пока не выпускается; эта версия готовит структуру для будущей установки. Пакет предназначен для Windows x64. Фактические проверки выполнены на Windows 11; другие версии Windows требуют отдельной проверки. Готовых macOS/Linux/Android/iOS/TV-пакетов нет.

## Профиль пользователя

Новые Windows-профили используют `%LOCALAPPDATA%\Orbita`, включая `inbox.sqlite`, `orbita.log` и `backups`. Запись в каталог программы для обычной работы не требуется. Данные разных Windows-пользователей разделены средствами ОС.

Для совместимости прежняя установка с существующей базой в `%LOCALAPPDATA%\UrayAssistant` продолжает использовать её. Если база уже есть в новом каталоге, выбирается она. Приложение не копирует и не объединяет разные базы молча. Не создавайте вторую пустую базу поверх старой ради обновления.

Переменная `AUTOMATION_HOME` явно задаёт другой каталог данных для тестирования или отдельного профиля. Это не многопользовательская синхронизация. По умолчанию её устанавливать не требуется. В Windows один и тот же профиль открывается одним GUI-процессом; отдельные явно заданные профили не блокируют друг друга.

Миграция создаёт SQLite backup и проверяет его целостность. При ручном переносе данных сначала полностью завершите приложение. Сохраните текущую базу и резервные копии; не копируйте единственный файл открытой базы. Программа не переносит расписания в другой часовой пояс автоматически.

## Зависимости функций

Для напоминаний, проектов и практики интернет не нужен. Свежая погода и поиск городов требуют доступности Open-Meteo. Системное определение зависит от службы и разрешений ОС; ручной выбор остаётся доступным. Плановые задачи выполняются только при запущенном приложении и бодрствующем устройстве. Программа не обходит сетевые ограничения и не гарантирует доступность внешнего сервиса.
