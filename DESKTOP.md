# Орбита: desktop-приложение

Актуальная Windows-программа: `dist/Orbita/Orbita.exe` вместе с `_internal`. Отдельный Python или аккаунт Codex для готового пакета не нужен. Старый Tk-прототип заменён совместимым входом в текущий Qt UI.

Для пользователя: [руководство](release_docs/USER_GUIDE.md), [первый запуск](release_docs/START_HERE.md), [данные и перенос](release_docs/PORTABLE.md).

Для разработки: [START_HERE](docs/START_HERE.md), [BUILDING](docs/BUILDING.md). CLI публикации сохранён: `Orbita.exe --publish-file результат.json` или `python publish.py --file результат.json`.

Почтовые скрипты — исторический отдельный эксперимент; они не входят в поставку и не используются Орбитой.
