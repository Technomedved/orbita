# Орбита: правила продолжения проекта

- Сначала прочитайте `docs/START_HERE.md`, `docs/HANDOFF.md` и `docs/ARCHITECTURE.md`. Уточняйте состояние по исходникам, а результаты проверок — по локальным отчётам.
- Общайтесь с пользователем по-русски. В каждом итоговом ответе давайте кликабельную ссылку с абсолютным путём на папку готовой программы. Используйте абсолютный путь текущего checkout к `dist/Orbita`.
- Сохраняйте стеклянный визуальный стиль и прозрачные сглаженные углы. Демонстрационные кнопки и фиктивные результаты в обычный интерфейс не добавляйте.
- Предметная логика и read models не должны импортировать Qt, `windows_integration` или обращаться к ОС через Win32. Платформенные функции и UI — отдельные адаптеры.
- Не считайте Windows exe готовым пакетом для других ОС. Непроверенные платформы явно помечайте. Мобильные фоновые задачи требуют отдельного адаптера.
- Сохраняйте существующие данные, стабильные ID задач и JSON-публикацию. Перед изменением схемы нужна проверяемая резервная копия; новые автоматизации выключены до настройки.
- Почта, корпоративные подключения, обязательный облачный API и сетевой сервер в текущий продукт не входят. SQL учебных материалов хранится как текст и не выполняется на SQLite.
- Выполняйте содержательные проверки изменённого поведения; для общей проверки есть `run_checks.py`. Собирайте и проверяйте Windows-пакет перед выдачей готовой версии.
- Обновляйте руководство, `docs/CHANGELOG.md` и `docs/HANDOFF.md`, когда меняете возможности, архитектуру или ограничения. Документация включается в пакет сборки.

- Для местоположения/времени прочитайте `docs/GEOLOCATION.md`: не запрашивайте датчики до действия пользователя или сохранённого opt-in; IP-геолокация не используется. Не переносите старые напоминания в новый пояс молча.
- Продукт предназначен для разных пользователей: город, опыт и ноутбук автора не являются настройками по умолчанию. Для поставки прочитайте `docs/DISTRIBUTION.md`. В exe копируется только справка из `release_docs`; AGENTS, HANDOFF, локальные отчёты и базы не распространяются.
