# История изменений

## Подготовка репозитория — 2026-10-18 (без изменения версии продукта)

- Локальная история Git, MIT для собственного кода, публичный README и инструкции участия/публикации.
- Исключения локальных секретов, сборок и прежнего почтового архива; проверка содержимого Git index.
- Перечень сторонних компонентов; аудит бинарных лицензий остаётся условием публичного релиза.
- Код приложения, схема базы и готовый exe не изменены.
- Проверка чистого клонирования выявила зависимость теста сохранения проектов от системной кодировки. Дочерний Python теста явно использует UTF-8; поведение продукта не изменено.

## 0.9.0 — профиль для каждого пользователя

- «Погода для поездок» переименована в «Отчёт о погоде». Миграция 7 → 8 с backup меняет только точное стандартное имя, сохраняя собственные названия, id, параметры и историю.
- Пустой новый профиль, выключенные шаблоны, ежедневный стандартный погодный отчёт; общий welcome с системным/ручным IANA-поясом, уведомлениями и необязательной погодой. Без погоды новые напоминания используют выбранный пояс.
- Новые Windows-данные в LOCALAPPDATA/Orbita, автоматическое сохранение старого пути при существующей базе. Изоляция mutex по профилю. В новом профиле закрепление поверх окон выключено.
- Удалён неявный fallback прогноза на прежний город и текст про маршрут. Старый Tk-вход направляет в текущий UI; launcher и spec больше не зависят от пользователя/диска автора.
- В сборку входит только нейтральная пользовательская справка; базы, секреты и журнал разработки исключены и проверяются. Документация разработчика остаётся в исходниках. Структура подготовлена для будущего установщика; сам установщик ещё не создан.
- Добавлены проверки чистого профиля, миграции имён, отдельных данных и первого запуска; `verify_distribution_release.py` проверяет перемещённый exe без путей к среде разработки.

## 0.8.0 — производительность и большие базы

- Индексированные чтения последнего запуска, календарного дня и цепочек напоминаний; миграция 6 → 7 с проверенной копией без удаления данных.
- Планировщик проверяет слоты одной пачкой и читает только готовую очередь; холостой проход не захватывает по одной пишущей транзакции на задачу. Перед захватом повторно проверяется срок повтора под блокировкой.
- Кэш стеклянного фона с обновлением при изменении размера/масштаба; статичные пустые карточки и настройка анимаций. Скрытое/свёрнутое окно откладывает ленту и перерисовку, сохраняя выполнение и доставку.
- Порционное отображение задач и проектов по 20 карточек, задержка поиска 200 мс, фильтрация/ограничение проекта до загрузки шагов. Настройки читаются одним снимком; форматирование времени не открывает SQLite для каждой строки.
- Повторяемые офлайн-замеры, проверки сохранения данных/конкуренции и готового exe. Числа и границы сравнения: PERFORMANCE.md.

## 0.7.0 — следующий день

- Отдельный раздел «Завтра» с датой/поясом, фокусом, связанными проектами и хронологической лентой планов. Добавление напоминания на завтрашнюю дату.
- Одноразовые/повторяющиеся задачи, ожидающие повторы и snooze через полночь; просмотр не выполняет задачи и не создаёт уведомления.
- Общая погодная панель, два прогноза по точным датам в одном обновлении, совместимость weather_snapshot и ограниченный weather_forecasts. Unix timestamps для IANA/DST, запас границ API; частичный сбой не перезаписывает кэш.
- Автоматическая смена даты, чтение всех слотов длинного дня, сохранение старых маршрутов/данных/JSON. Схема остаётся 6.
- Документ TOMORROW.md, core/UI/packaged проверки; 145 общих тестов и 101 проверка ядра (подмножество).

## 0.6.0 — местоположение и часовые пояса

- Убрана персональная привязка обычного приложения к Ураю. Свежая установка предлагает место; обновление сохраняет прежний профиль до выбора.
- Системная геолокация по согласию, ручной поиск с регионами, координаты/IANA без поиска, сохранение и повторный вход из настроек.
- Отдельный opt-in одной попытки определения при открытии; отказ/сеть не стирают сохранённое место. IP не используется.
- Настраиваемые часы трёх погодных карточек; чужой прогноз не отображается, запоздалый ответ отменяется при фиксации.
- Явные IANA-пояса расписаний и тихих часов, DST, сохранение поясов существующих напоминаний при переезде.
- Схема 6 с backup и проверкой; read model «Сегодня» 2; JSON/CLI совместимы. В Windows-пакет включены Qt Positioning и tzdata.
- Документ GEOLOCATION.md, новые core/UI/packaged проверки. Настоящее получение координат требует разрешения ОС, не подменяется тестовым успехом.

## 0.5.0 — обзор дня и подготовка дальнейшей разработки

- На «Сегодня» добавлены реальные ожидающие напоминания, сегодняшнее расписание и следующие шаги проектов.
- Удалены пользовательские кнопки тестового уведомления и галереи погодных сцен. Старые `Демо` сохранены в SQLite и скрыты из обычной выдачи; smoke больше не создаёт карточку.
- Настройки доступны из шапки любой вкладки. Добавлены «О приложении», встроенное руководство, открытие папок программы/документации.
- Навигация перестраивается по ширине; длинный редактор расписания прокручивается, сохраняет доступ к кнопкам и скрывает неподходящие поля.
- Подробности запуска показывают читаемые поля вместо JSON. Добавлен фильтр личных напоминаний.
- Escape сохраняет несохранённый SQL/заметки перед закрытием редактора.
- Общие Qt-компоненты вынесены в `ui_components.py`; пути/версия/время — в `app_config.py`. Доменная модель расписаний больше не импортирует хранилище.
- Добавлен `build_desktop.py`, закреплены desktop-зависимости, убрано имя конкретного пользователя из Windows-сборщика. Документация включается в пакет.
- Добавлены core/read-model/portable-path/UI-проверки. В Windows прошли 89 общих и отдельно 64 core-проверки; итоговые отчёты находятся в `data/checks-*.json`.
- Схема осталась 5. macOS/Linux/mobile/TV ещё не выпущены и не проверены на соответствующих ОС.
