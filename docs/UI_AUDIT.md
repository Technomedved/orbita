# Аудит пользовательского интерфейса 0.5.0

Критерий: элемент остаётся в обычном UI, если помогает пользователю получить результат, изменить реальные данные/расписание, понять состояние или открыть помощь. Разработческие демонстрации не должны создавать пользовательскую историю и занимать место в панели.

## Разбор по экранам

| Экран/элемент | Решение | Назначение / изменение |
|---|---|---|
| Шапка, закрепление | Оставить | Реальный режим поверх окон, сохраняется |
| Свернуть / крестик | Оставить | Панель задач / трей; крестик не останавливает автоматизации |
| Настройки | Перенести в шапку | Доступны с каждой вкладки, а не только под погодой |
| Навигация | Доработать | Пять пунктов в ряд при достаточной ширине, два ряда в узком окне |
| Нижний «Тест уведомления» | Удалить из UI | Кнопка создавала искусственную запись «Демо» |
| Нижний «О приложении» | Добавить | Версия, руководство, папка программы, комплект документации |
| Индикатор состояния | Оставить | Отличает общую паузу и тихий режим |
| Уголок изменения размера | Оставить | Рабочий элемент управления геометрией |
| «Сегодня» / обзор | Добавить | Настоящие ожидающие напоминания, расписание и проекты |
| Карточки погоды | Оставить | Утро/день/вечер, актуальность и параметры поездок |
| «Обновить» | Оставить | Получение прогноза по запросу, не тест |
| «Анимации» / галерея сцен | Удалить из UI | Демонстрировала все погодные состояния; анимация реального прогноза остаётся |
| Пустые погодные значения | Оставить как состояние | При отсутствии данных отображаются прочерки, не выдуманный прогноз |
| Лента и фильтры | Доработать | Добавлен фильтр «Напоминания», «Демо» исключено до LIMIT |
| «Прочитать всё» | Оставить | Реальное действие с состоянием ленты |
| Автоматизации / ручной запуск | Оставить | Нужен для полезного результата без включения расписания |
| Включение/пауза | Оставить | Управление конкретной задачей; отличается от общей паузы |
| Редактор расписания | Доработать | Прокрутка, постоянные кнопки сохранения/отмены, только подходящие текущему повторению поля |
| Правила пропусков/повторов | Оставить | Реальная надёжность после сна/сбоев, не тестовая настройка |
| Журнал/история задачи | Оставить | Помогает понять реальное выполнение |
| Подробности запуска | Доработать | Читаемые времена/статус/попытки/ошибка вместо сырого JSON |
| Обучение / диагностика | Оставить | Это учебная диагностика пользователя, не программный тест; запуск необязателен |
| SQL/заметки/подсказки/эталон | Оставить | Полноценный учебный процесс; эталон скрыт до запроса |
| Самооценка/завершение | Оставить | Самостоятельные отметки без фиктивной автоматической оценки |
| Вопрос для Codex | Оставить | Подготовка копируемого текста, отправки нет |
| Проекты/шаблоны/шаги | Оставить | Реальные пользовательские данные, шаблоны применяются только по выбору |
| Проектные заметки/ссылки | Оставить | Материалы проекта; ссылки открываются явно |
| Проектное напоминание | Оставить | Следующий шаг и возврат к проекту, одно связанное расписание |
| Явное «Сохранить» при автосохранении | Оставить | Даёт возможность сохранить сразу и повторить при ошибке |
| Тихий режим/тихие часы | Оставить, сократить форму | Времена показываются только при включённых тихих часах |
| Автозапуск Windows | Оставить на Windows | На других платформах этот конкретный пункт не показывается |

## Диагностические данные и инструменты

Старые `Демо`-события не удаляются из базы, но не попадают в пользовательскую ленту, всплытие, счётчик аудита или «Сегодня». Это очистка представления с сохранением истории. Внешний JSON-публикатор остаётся рабочим интерфейсом автоматизаций.

`--smoke-test` больше не публикует пример уведомления. `--capture` и `--verify-corners`, скрипты `verify_*`, тесты и benchmark остаются средствами разработки. Обычный запуск их не выполняет. Снимки/отчёты/старые GIF в `data` не копируются в программу.

## Что осмотрено и проверено

Шапка, обе ширины навигации, пустой/заполненный «Сегодня», погода, лента, задачи и редактор, журнал и детали, обучение/редактор/самооценка/вопрос, проекты/заметки/ссылки/напоминание, настройки, «О приложении», руководство, всплывающее окно. Автотесты дополнительно проверяют открытие проекта из обзора, доступность настроек с другой вкладки, фиксированную кнопку сохранения при маленькой высоте и сохранение черновиков по Escape.

Узкие окна прокручиваются; исправление прозрачных углов сохраняется. TV/D-pad и мобильная touch-навигация в этот аудит не входят и будут отдельной проверкой целевой платформы.

## Дополнение 0.6.0

Добавлены первый выбор места и кнопки входа из «Сегодня»/настроек; это рабочие элементы, не демонстрации. Результат поиска требует явного выбора и сохранения. Системные настройки Windows открываются только своей кнопкой. Сохранение недоступно без выбранного места, а кнопки сохранения/откладывания находятся вне прокрутки. Вкладки, списки результатов и дробные поля оформлены в общей стеклянной палитре. Устаревший/чужой прогноз очищается с пояснением.

## Дополнение 0.7.0

«Завтра» — рабочая шестая страница с пассивным календарным планом; старые маршруты сохранены. Новые действия: добавление на нужную дату, настройка исходной задачи, открытие связанного проекта/реального snooze, порции длинной ленты. Кнопок «Выполнено» для ещё не наступившего планового события нет. Погодная панель общая для обеих дат. Шесть разделов укладываются в два ряда на узком окне и один на широком. Просмотрены пустой/наполненный обзор, обе ширины, разные погодные даты и редактор.
