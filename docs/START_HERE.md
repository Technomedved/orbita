# Орбита: начало работы с проектом

Текущая версия: **0.9.3**. Рабочий продукт — локальное приложение для Windows. macOS, Linux, Android, iOS и Android TV — направления дальнейшего переноса; готовых пакетов этих платформ нет.

## Для пользователя

Для установки используйте Windows-установщик из [выпуска 0.9.3](https://github.com/Technomedved/orbita/releases/tag/v0.9.3). Он работает в профиле пользователя, сохраняет данные при обновлении и предлагает их сохранение при удалении. Переносимый ZIP также доступен; подробнее — [INSTALLER.md](INSTALLER.md).

Запустите `Orbita.exe` из папки программы вместе с `_internal`. Обычный интерфейс содержит «Сегодня», «Завтра», «Автоматизации», «Журнал», «Обучение», «Проекты». Настройки доступны через шестерёнку в шапке, руководство и папки — через «О приложении». Для обычной работы: [USER_GUIDE.md](USER_GUIDE.md). Подробности реализации и эксплуатации: [MANUAL.md](../MANUAL.md).

## Что передать в новый чат

Минимальный набор: этот файл, [HANDOFF.md](HANDOFF.md), [ARCHITECTURE.md](ARCHITECTURE.md) и исходники проекта. Для переноса на другую ОС добавьте [CROSS_PLATFORM.md](CROSS_PLATFORM.md), [DATA_MODEL.md](DATA_MODEL.md), [CONTRACTS.md](CONTRACTS.md).

Документация разработки лежит в `docs` исходного проекта. В готовый пакет копируется только пользовательская справка из `release_docs`, без журналов разработки и личного контекста. Сами исходники находятся в корне проекта рядом с Orbita.spec; exe и документация не заменяют исходный код. Пользовательская база хранится отдельно от программы, в новых Windows-профилях — `%LOCALAPPDATA%\Orbita\inbox.sqlite`; прежняя база сохраняет свой путь.

## Правило актуальности

Документы описывают намерения и состояние релиза; истина об исполнении — исходники и результаты проверок. Наличие инструкции для macOS не означает, что macOS-сборка уже проверена. Последние результаты смотрите в `data/checks-desktop.json`, `data/checks-core.json` и `data/product-release-verification.json` исходного проекта; сведения о готовом пакете — в `release-manifest.json` рядом с программой.
