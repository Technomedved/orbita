# Практика IBM Db2 в Орбите

Откройте **Обучение** в приложении. Начните с диагностики, затем отметьте пробелы в «Самооценке» и завершите диагностику самостоятельно. Порядок следующих занятий будет учитывать самооценку и зависимости тем.

Стартовый набор:

1. LEFT JOIN и подсчёт опубликованных версий, включая документы без публикаций.
2. Предварительная агрегация двух дочерних наборов: версии и права.
3. NULL, NOT IN и поиск отсутствия активного READ-доступа через NOT EXISTS.
4. Последняя версия с детерминированным порядком при одинаковом времени.
5. Составной отчёт о проблемах архива с CTE и флагами.
6. Полуоткрытые диапазоны дат, пограничные времена и обсуждение индекса.

Каждое занятие рассчитано на 15–20 минут. Материалы, решения и ссылки на официальную документацию IBM хранятся в `db2_content.py`, отдельно от интерфейса. Здесь только IBM Db2; другие курсы пока не создаются.

[orbita-db2-fixture.sql](orbita-db2-fixture.sql) содержит четыре вымышленные таблицы и 25 строк. Скрипт создаётся функцией `fixture_sql()` того же каталога, доступен для копирования/сохранения в приложении. Запускать его нужно вручную в отдельной учебной схеме через DBeaver. Он не удаляет объекты, не предназначен для повторного запуска в заполненной схеме и не настраивает платформенные табличные пространства или права.

Платформа и версия Db2 не предполагаются. DBeaver — клиент; используйте документацию своего сервера. Например, [IBM SQL Reference для Db2 LUW 12.1.2](https://public.dhe.ibm.com/ps/products/db2/info/vr121/pdf/en_US/db2_sql_reference_1212.pdf) описывает именно LUW 12.1.2, а не любую Db2. Ссылки других платформ помечены в занятиях.

В среде разработки нет сервера Db2: DDL и эталоны не выполнялись на нём. Ожидаемые строки отдельно проверены расчётами в Python. SQLite используется только для данных Орбиты; Db2 SQL на ней не исполняется. Самостоятельное завершение занятия не является подтверждением правильности запроса.
